# Portfolio Overview

## Business Problem
Retail teams need a clear view of sales, profitability, product performance and regional trends to support commercial decisions.

## Analysis Workflow
1. Validate transaction fields and data types.
2. Explore sales and profit distributions in Excel/Python.
3. Use MySQL for grouped KPIs, ranking and time-series analysis.
4. Create reusable Power BI measures with DAX.
5. Present findings through an executive dashboard.

## Core KPIs
- Total Revenue
- Total Profit
- Total Orders
- Average Order Value (AOV)
- Profit Margin
- Revenue by Region
- Revenue by Category/Product
- Monthly Revenue Trend

## Portfolio Evidence
This repository demonstrates practical use of **Excel, SQL, Python, Pandas, Matplotlib, Power BI and DAX**.

> The GitHub dataset is a compact synthetic sample. It is intentionally small for repository review; the project logic is designed to scale to the full transaction dataset.
