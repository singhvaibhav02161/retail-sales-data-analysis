# Retail Sales Data Analysis & Dashboard
**Tools:** Excel, MySQL, Python (Pandas/Matplotlib), Power BI

## Objective
Analyze 10,000 retail transactions to understand revenue, profit, regional/category performance, product performance and monthly trends.

## Workflow
Data validation → Excel exploration → SQL analysis → Python EDA → Power BI dashboard.

## Power BI pages
- Executive Overview: Revenue, Profit, Orders, AOV, Profit Margin
- Regional Performance
- Product & Category Analysis
- Monthly Trends

**Dataset note:** This is a synthetic portfolio dataset created for demonstration and practice.
